# 🎮 Criando um Dashboard de Vendas do Xbox com Excel

![Excel](https://img.shields.io/badge/Excel-Dashboard-green)

## 📋 Descrição

Dashboard de vendas desenvolvido no Microsoft Excel a partir de uma base de dados de assinantes do Xbox. O projeto abrange desde a extração e tratamento dos dados até a criação de indicadores-chave (KPIs) para monitoramento do desempenho comercial.

## 📌 Contexto

Este dashboard foi construído com base em uma planilha contendo **295 registros** de assinantes do ecossistema Xbox, com dados sobre planos (Core, Standard, Ultimate), tipos de assinatura (Mensal, Trimestral, Anual), passes de jogos (EA Play e Minecraft), valores de cupons e receita total.

Período analisado: **Janeiro a Dezembro de 2024**
